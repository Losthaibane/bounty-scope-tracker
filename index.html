Assets added to program scopes in the last 120 days — freshest hunting ground first. Removed assets and resolved-report deltas appear from the second daily run onward.

Score components (0–100)

  • +0–30 — newest in-scope asset age (linear decay over 90 days). Fresh scope = untested surface.
  • +0–15 — last resolved report: ≤14d = 15, ≤60d = 8, ≤180d = 2. Proves the program actually pays out.
  • +0–25 — weighted scope breadth: wildcards/CIDR ×5, APIs & apps ×4, hardware/source ×3, domains/URLs ×1.
  • +0–10 — response efficiency ≥80% = 10, ≥50% = 5. Slow programs waste your time.
  • +15 — offers bounties, +5 more if average ≥ $500.
  • −10 — more than 70% of listed assets are out of scope.

Data sources & coverage

All public, no credentials, refreshed daily by a GitHub Actions cron job. Tune weights in scraper.py.

  • HackerOne — directory + anonymous GraphQL: full stats and per-asset scope timestamps.
  • YesWeHack — public API: scope lists, real average rewards, reports in last 7 days. Scope changes detected by daily diff (from run 2).
  • Intigriti — public list API: bounty range, last program update, last submission. Scope detail needs an account, so breadth columns show "—".
